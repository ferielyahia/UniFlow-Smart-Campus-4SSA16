# UniFlow – Smart Campus

## Présentation
UniFlow est une application de gestion intelligente d'un campus universitaire basée sur une architecture microservices.

## Objectifs
- Centraliser la gestion des étudiants.
- Gérer les cours et les emplois du temps.
- Suivre les présences et les absences.
- Gérer les salles et les réservations.
- Organiser les événements de la vie universitaire.

## Équipe

## Architecture
Le projet utilise une architecture microservices avec des bases de données indépendantes et une communication entre les services.

## Technologies
- Java / Spring Boot
- Spring Cloud
- REST API
- MySQL / PostgreSQL / MongoDB (selon les besoins)
- Docker
- Git / GitHub
